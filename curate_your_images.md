## 2. Real Captures vs. AI Choices: Strategic Call & Rationale

> [!IMPORTANT]
> **Core Engineering Rule:** Never use AI stand-ins for work or human identity. AI generation is reserved exclusively for passive ambient styling (connective tissue).

### A. Real Work Captures (Why Real Beats AI for Proof)
1. **FL-01 Workflow Audit Spreadsheet (`03_real_fl01_audit_screenshot.png`)**:
   - *Call:* Used a clean, high-resolution crop of the actual audit spreadsheet.
   - *Strategic Rationale:* An AI-generated concept table contains gibberish text and fake columns. A hiring CTO evaluates real numbers: task names, baseline hours, tool pairings, and reliability scores. Real data builds instant empirical authority.
2. **FL-02 Prompt Iteration & Benchmark Log (`04_real_fl02_prompt_log_screenshot.png`)**:
   - *Call:* Used an un-retouched IDE code editor screenshot showing markdown syntax highlighting.
   - *Strategic Rationale:* Prompt engineering cannot be proven with flashy illustrations. Showing the exact naive prompt vs structured JSON schema prompt in VS Code proves real runtime execution and systematic laddering.
3. **Live Agent Runtime Execution Engine (`05_real_agent_app_screenshot.png`)**:
   - *Call:* Used a live dashboard capture of the Next.js Agent Runner.
   - *Strategic Rationale:* Anyone can generate an abstract picture of a "robot coding." Capturing actual terminal output logs (`grep_search`, `replace_file_content`, pass/fail status) proves software engineering execution.
4. **Cal.com Calendar Widget (`08_real_calcom_widget_screenshot.png`)**:
   - *Call:* Used an authentic screenshot of the embedded Cal.com booking interface.
   - *Strategic Rationale:* Ensures zero conversion friction. Visitors instantly recognize standard Cal.com UI patterns and feel safe booking a 15-minute slot.

### B. Real Headshot Photo (Why Authentic Person Beats AI Avatar)
- **Engineer Profile Headshot (`06_real_engineer_headshot.png`)**:
  - *Call:* Used a real, professional studio photograph of the student engineer at a workspace.
  - *Strategic Rationale:* AI-generated avatars (e.g. hyper-polished Midjourney faces, cyberpunk character renders) immediately signal synthetic dishonesty. CTOs hire human engineers who take ownership of production outages. An authentic face creates personal trust and professional accountability.

## 3. AI Connective Tissue Visual Kit & Prompt Iteration Log

To prevent AI-generated elements from looking like an inconsistent "pile of random images," all connective tissue elements were generated using a strict, unified **Visual Kit Specification**.

### Visual Kit Design Tokens
- **Background Base:** Dark Slate `#0B0F19` (Matte, non-reflective)
- **Card Surface:** Glassmorphic translucent `#111827` with 1px border `#1F2937`
- **Accent Lighting:** Cyan `#06B6D4` (Primary active node) & Indigo `#6366F1` (Secondary glow)
- **Geometry & Composition:** Minimal isometric grid lines, subtle node network traces, flat vector depth.

### Prompt Iteration Log (Holding Style Steady)

```markdown
Iteration 1 (Naive Prompt — Too Volumetric & Sci-Fi Cliché):
Prompt: "Cool AI background for developer portfolio website with glowing network nodes and futuristic cyber lighting."
Result: Excessive bright lens flares, glowing brain imagery, and intense blue neon light trails. Ruined text readability and looked like a generic stock template.

Iteration 2 (Refining Color Hex & Surface Style — Getting Closer):
Prompt: "Dark mode slate background #0B0F19, glassmorphic UI card wireframes, subtle cyan #06B6D4 node lines, indigo ambient glow, clean developer dashboard style."
Result: Good color palette, but lighting was slightly too harsh on the top-right quadrant, creating asymmetrical visual distraction.

Iteration 3 (Final Keeper Prompt Baseline — Perfect Style Lock):
Prompt: "Sleek dark slate #0B0F19 background texture for a developer portfolio hero section. Minimalist glassmorphic UI card wireframes with subtle cyan #06B6D4 and indigo #6366F1 isometric grid node lines. Matte dark finish, high-end developer dashboard visual texture, clean, modern UI backdrop without text."
Result: Perfect visual kit alignment. Zero clutter, soft ambient lighting, high contrast for body text overlay. Used across all connective tissue elements.
```

## 4. Ruthless Curation & Graded Rejection Log

Discernment is demonstrated by what you **reject**, not just what you keep. Below are 1-to-2 line technical evaluations of AI-generated images that were discarded during curation.

### Rejection Analysis 1: Glowing Sci-Fi Core (Discarded Candidate)

> [!WARNING]
> **Rejection Note (Graded Discernment):**  
> *Rejected for sci-fi cliché and visual clutter.* The intense volumetric central glow (`>850 nits` highlight) and glowing energy vortex destroy body copy text contrast (`<2.8:1` contrast ratio), making headline legibility impossible. It signals junior "stock template" aesthetic rather than serious engineering rigor.

---

### Rejection Analysis 2: Light-Mode Saturated Stock Ribbon (Discarded Candidate)

> [!WARNING]
> **Rejection Note (Graded Discernment):**  
> *Rejected for off-brand color gamut breach.* The bright white/light-gray background violates the portfolio's core dark slate theme (`#0B0F19`), causing severe visual disruption when navigating between pages. The floating 3D ribbon lacks any technical connection to AI architecture or code workflows.

---

### Rejection Analysis 3: Saturated Neon Magenta Delegation Node (Discarded Candidate)

> [!WARNING]
> **Rejection Note (Graded Discernment):**  
> *Rejected for visual set drift.* The high-saturation neon magenta (`#FF007F`) violates the visual kit's strict cyan/indigo color tokens, creating a disjointed "pile of images" feel rather than a cohesive design system. The intense bloom effect draws the eye away from the AI delegation methodology copy.
